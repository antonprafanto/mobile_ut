# Navigation

Navigation adalah salah satu aspek terpenting dalam aplikasi mobile. Module ini akan mengajarkan berbagai pattern navigasi di Ionic.

## Angular Router Basics

Ionic menggunakan Angular Router untuk navigasi. Router sudah dikonfigurasi di `app.routes.ts`.

### Basic Navigation

```typescript
// app.routes.ts
import { Routes } from '@angular/router';

export const routes: Routes = [
  {
    path: '',
    redirectTo: 'home',
    pathMatch: 'full'
  },
  {
    path: 'home',
    loadComponent: () => import('./pages/home/home.page').then(m => m.HomePage)
  },
  {
    path: 'about',
    loadComponent: () => import('./pages/about/about.page').then(m => m.AboutPage)
  },
  {
    path: 'products/:id',
    loadComponent: () => import('./pages/product-detail/product-detail.page').then(m => m.ProductDetailPage)
  }
];
```

### Navigasi Programmatic

```typescript
import { Router } from '@angular/router';
import { NavController } from '@ionic/angular';

export class HomePage {
  constructor(
    private router: Router,
    private navCtrl: NavController
  ) {}

  // Method 1: Angular Router
  goToAbout() {
    this.router.navigate(['/about']);
  }

  // Method 2: NavController (Recommended untuk Ionic)
  goToProducts() {
    this.navCtrl.navigateForward('/products');
  }

  // Dengan parameter
  viewProduct(id: number) {
    this.navCtrl.navigateForward(`/products/${id}`);
  }

  // Dengan query params
  searchProducts() {
    this.navCtrl.navigateForward('/products', {
      queryParams: { category: 'electronics', sort: 'price' }
    });
  }

  // Navigate back
  goBack() {
    this.navCtrl.back();
  }
}
```

### Navigation di Template

  Back
</ion-button>

## Tabs Navigation

Tabs adalah pattern navigasi paling umum untuk bottom navigation.

### Setup Tabs

```bash
ionic generate page tabs/tabs --skip-tests
ionic generate page tabs/tab1 --skip-tests
ionic generate page tabs/tab2 --skip-tests
ionic generate page tabs/tab3 --skip-tests
```

### tabs.routes.ts

```typescript
import { Routes } from '@angular/router';

export const routes: Routes = [
  {
    path: 'tabs',
    loadComponent: () => import('./tabs.page').then(m => m.TabsPage),

      {
        path: 'tab1',
        loadComponent: () => import('./tab1/tab1.page').then(m => m.Tab1Page)
      },
      {
        path: 'tab2',
        loadComponent: () => import('./tab2/tab2.page').then(m => m.Tab2Page)

      {
        path: 'tab3',

        pathMatch: 'full'
      }
    ]
  },
  {
    path: '',
    redirectTo: 'tabs',
    pathMatch: 'full'
  }
];
```

### app.component.ts

```typescript
import { Component } from '@angular/core';
import { Router } from '@angular/router';

export class AppComponent {
  selectedPath = '';
  
  appPages = [
    { title: 'Home', url: '/home', icon: 'home' },
    { title: 'Products', url: '/products', icon: 'cart' },
    { title: 'Orders', url: '/orders', icon: 'list' },
    { title: 'Settings', url: '/settings', icon: 'settings' }
  ];

  constructor(private router: Router) {
    this.router.events.subscribe(() => {
      this.selectedPath = this.router.url;
    });
  }

  logout() {
    // Logout logic
    this.router.navigate(['/login']);
  }
}
```

## Stack Navigation

Untuk detail pages, gunakan stack navigation.

### Passing Data

**Method 1: Route Parameters**

```typescript
// Navigate dengan ID
this.navCtrl.navigateForward(`/products/${productId}`);

// Receive di destination page
import { ActivatedRoute } from '@angular/router';

export class ProductDetailPage implements OnInit {
  productId: string;

  constructor(private route: ActivatedRoute) {}

  ngOnInit() {
    this.productId = this.route.snapshot.paramMap.get('id')!;
    this.loadProduct(this.productId);
  }
}
```

**Method 2: Navigation Extras (State)**

```typescript
// Send data
this.navCtrl.navigateForward('/product-detail', {
  state: {
    product: {
      id: 1,
      name: 'Laptop',
      price: 15000000
    }
  }
});

// Receive data
import { Router } from '@angular/router';

export class ProductDetailPage {
  product: any;

  constructor(private router: Router) {
    const navigation = this.router.getCurrentNavigation();
    if (navigation?.extras.state) {
      this.product = navigation.extras.state['product'];
    }
  }
}
```

**Method 3: Service (Recommended untuk complex data)**

```typescript
// data.service.ts
@Injectable({ providedIn: 'root' })
export class DataService {
  private selectedProduct: any;

  setProduct(product: any) {
    this.selectedProduct = product;
  }

  getProduct() {
    return this.selectedProduct;
  }
}

// From list page
constructor(private dataService: DataService) {}

viewProduct(product: any) {
  this.dataService.setProduct(product);
  this.navCtrl.navigateForward('/product-detail');
}

// In detail page
ngOnInit() {
  this.product = this.dataService.getProduct();
}
```

## Navigation Guards

Protect routes dengan guards (authentication, etc).

```typescript
// auth.guard.ts
import { inject } from '@angular/core';
import { Router } from '@angular/router';
import { AuthService } from './auth.service';

export const authGuard = () => {
  const authService = inject(AuthService);
  const router = inject(Router);

  if (authService.isAuthenticated()) {
    return true;
  }

  router.navigate(['/login']);
  return false;
};

// app.routes.ts
{
  path: 'profile',
  loadComponent: () => import('./profile/profile.page').then(m => m.ProfilePage),
  canActivate: [authGuard]
}
```

## Page Transitions

### Custom Animations

```typescript
import { NavController } from '@ionic/angular';
import { AnimationController } from '@ionic/angular';

export class HomePage {
  constructor(
    private navCtrl: NavController,
    private animationCtrl: AnimationController
  ) {}

  async navigateWithCustomAnimation() {
    const animation = this.animationCtrl.create()
      .addElement(document.querySelector('.page-to-animate')!)
      .duration(500)
      .fromTo('opacity', '0', '1')
      .fromTo('transform', 'translateX(100px)', 'translateX(0)');

    await this.navCtrl.navigateForward('/about', {
      animation
    });
  }
}
```

## Deep Linking

Setup untuk handle external links.

```typescript
// capacitor.config.ts
{
  appId: 'com.myapp',
  appName: 'MyApp',
  plugins: {
    App: {
      deeplinks: [
        { scheme: 'myapp', path: '/products/:id' }
      ]
    }
  }
}

// Handle deep link
import { App } from '@capacitor/app';

App.addListener('appUrlOpen', (event) => {
  const url = event.url;
  // Parse and navigate
  // Example: myapp://products/123
  const slug = url.split('/').pop();
  this.router.navigate(['/products', slug]);
});
```

## Best Practices

1. **Use NavController** untuk Ionic-specific animations
2. **Lazy Loading** untuk performa optimal
3. **Clear Navigation Stack** saat logout:
   ```typescript
   this.navCtrl.navigateRoot('/login');
   ```
4. **Handle Back Button** di Android:
   ```typescript
   import { Platform } from '@ionic/angular';
   
   constructor(private platform: Platform) {
     this.platform.backButton.subscribeWithPriority(10, () => {
       // Custom back button logic
     });
   }
   ```
